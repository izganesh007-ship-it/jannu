# Swati / Jannu Birthday Surprise

A 4-page mobile-first Next.js birthday experience.

## Run locally
npm install
npm run dev

## Deploy on Vercel
Import this folder/repository into Vercel. Framework preset: Next.js. No environment variables are required.

## Pages
/ — welcome
/candles — tap candles or optionally use microphone
/cake — swipe to cut
/letter — final birthday letter

The music interaction is intentionally not tied to a copyrighted commercial song. You can later add your own licensed audio if desired.
